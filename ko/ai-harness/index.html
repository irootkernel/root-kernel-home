AI Harness

AI와 소프트웨어를 개발하다 보면 새 대화에서 진행 중인 작업을 이어가고, 여러 AI의 코드 리뷰를 비교하고, 긴 테스트 로그에서 실패 원인을 찾아야 합니다. 여러 저장소에 나뉜 문서를 같은 기준으로 유지하는 일도 필요합니다.

루트커널은 이런 작업을 돕는 AI Harness 도구군을 직접 개발했습니다. 작업 상태를 보존해 다음에 할 일을 확인하고, 리뷰가 지적한 내용을 실제 코드와 대조합니다. 테스트 로그는 판정 근거를 남겨 요약하고, 문서는 기준 저장소와 동기화합니다. 이 도구들을 자사 개발에 활용하고 있으며, 오픈소스로 공개했습니다.

Aquarium

Aquarium은 AI 에이전트가 개발 도구를 준비하고 함께 활용할 수 있도록 돕는 플러그인입니다. 개발 환경을 점검해 필요한 도구의 설치와 프로젝트 설정을 돕고, 개발 중에는 작업 절차 관리, 테스트, 코드 리뷰, 문서 동기화에 필요한 도구를 연결합니다. Codex를 기반으로 개발했으며, Claude Code, Kimi Code, GLM을 위한 에디션도 제공합니다.

Podway

Podway는 작업 절차와 진행 상태를 기록해, 사람과 AI 에이전트가 작업을 이어갈 수 있도록 돕는 로컬 도구입니다. 새 대화에서 작업을 시작하거나 담당 에이전트가 바뀌어도 현재 단계와 필요한 기록, 다음에 가능한 행동을 확인할 수 있습니다. 재작업이 필요하면 절차에 정한 경로로 돌아가, 다시 수행해야 할 작업과 검증을 확인할 수 있습니다.

Dolgorae(돌고래)

Dolgorae는 Codex에 역할과 권한, 행동 규칙과 페르소나를 부여하는 상위 제어 계층입니다. 하나의 디렉터리에서 역할이 다른 여러 Codex 에이전트를 실행하고, 서로 소통하며 협업하도록 연결합니다.

저장소GitHub

Sanho(산호)

Sanho는 하나의 프로젝트가 여러 코드 저장소로 나뉘어 있을 때, 각 저장소의 문서를 하나의 기준 문서 저장소와 동기화하는 도구입니다. 서버와 클라이언트처럼 저장소가 나뉘어 있어도 각자의 코드 옆에서 문서를 수정하고, 변경 사항은 한곳에 모아 관리할 수 있습니다. 저장소 간 문서 차이를 감지하고 Git의 병합 방식으로 변경 내용을 맞추며, 충돌은 평소 사용하는 Git 작업 방식으로 해결합니다.

저장소GitHub

Mulgae(물개)

Mulgae는 여러 AI에 역할을 나눠 코드 리뷰를 맡기는 도구입니다. 검토할 코드를 스냅샷으로 고정해 모든 리뷰어가 같은 내용을 보도록 합니다. 각 AI가 독립적으로 작성한 보고서를 모으고, 지적의 근거를 검토 대상 코드와 대조합니다. 결과는 사람이 수정 여부와 우선순위를 판단할 수 있도록 보고서로 남깁니다.

저장소GitHub

Gaori(가오리)

Gaori는 테스트 명령을 실행하고, 긴 로그에서 실패를 확인하는 데 필요한 내용을 추려 주는 도구입니다. 사람과 AI는 요약과 관련 로그부터 살펴보고, 필요할 때 원본을 확인할 수 있습니다. 원본 출력은 그대로 보존하며, 테스트의 성공과 실패는 실행한 명령의 실제 종료 코드를 기준으로 전달합니다.

저장소GitHub

Sorage(소라게)

Sorage는 서로 다른 프로젝트에서 작업하는 AI 코딩 세션 사이에 문서와 검토 의견을 주고받는 도구입니다. 문서를 받은 쪽이 검토 의견을 남기면, 보낸 쪽은 이를 반영한 수정본을 다시 전달할 수 있습니다. 검토 진행 상황과 최종 수락한 문서 버전을 기록해, 무엇을 전달했고 어떤 내용에 합의했는지 확인할 수 있도록 합니다.
