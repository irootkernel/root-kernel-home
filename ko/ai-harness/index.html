AI Harness

AI Harness는 에이전트에게 개발을 맡기면서도 작업 상태, 완료 증거, 승인 권한을 사람의 통제 아래 두는 공개 도구군입니다.

Root Kernel은 규율을 문서로만 설명하지 않고 실제 도구에 구현해 공개합니다. 이 저장소들은 Root Kernel이 에이전트와 함께 개발하는 실제 방식이며, 우리 팀이 첫 번째 사용자입니다.

도구들은 작업 상태를 추적하고 완료 주장을 증거와 대조하며 중요한 변경의 승인 권한을 사람에게 남깁니다. 명령의 성공 여부는 실제 exit code로 판정하고, 검토 지적은 대조되기 전까지 참고 의견으로 취급합니다.

각 README는 도구가 무엇을 강제하고 무엇을 판정하지 않는지 먼저 밝힙니다. 에이전트가 실행할 수 있는 범위를 넓히되 최종 승인 권한은 사람에게 남기는 것이 공통 경계입니다.

Aquarium

Aquarium은 여러 도구를 하나의 계약 기반 workflow로 묶는 Codex 플러그인입니다. 계획이 승인되기 전에는 실행을 시작하지 않고, 각 단계가 어떤 도구를 부르며 어떤 증거를 받아야 하는지 기록합니다. 작업 종료도 선언된 계약과 사람의 승인 경계를 따릅니다.

저장소https://github.com/irootkernel/aquarium
에디션Claude Code·Kimi Code·ZCode

Podway

Podway는 한 Git worktree의 한 작업이 procedure graph를 벗어나지 않도록 지키는 로컬 도구입니다. 작업마다 절차를 세션 전에 선택하거나 구성하고 검사한 뒤 다이제스트를 고정해 실행 중 바뀌지 않게 합니다. 실행 중에는 선언된 경로만 허용하며, `podway observe`의 `allowed_actions`를 보고 사람이나 에이전트가 무엇을 할지 고릅니다. Podway는 작업을 수행하거나 기록의 의미가 참인지 검증하지 않습니다.

저장소https://github.com/irootkernel/podway

Dolgorae(돌고래)

Dolgorae는 오래 실행되는 에이전트에 안정된 신원, 쓰기 권한 조정, 복구 기능을 붙이는 로컬 제어 계층입니다. 실행이 중단돼도 같은 작업을 식별해 복구하고 감사 가능한 기록을 남깁니다. 대화 내용 자체를 수명주기 상태의 기준으로 삼지는 않습니다.

저장소https://github.com/irootkernel/dolgorae

Sanho(산호)

Sanho는 여러 애플리케이션 저장소의 문서를 하나의 기준 문서 저장소와 동기화합니다. Git merge와 충돌 규칙을 그대로 따르며, 충돌 해결과 공개를 위한 `git push`는 사용자가 결정합니다. 변경된 문서를 충돌 없이 동기화하는 `sanho sync`는 `[SANHO] Sync docs to <oid>` 커밋을 만들 수 있습니다.

저장소https://github.com/irootkernel/sanho

Mulgae(물개)

Mulgae는 immutable snapshot을 여러 provider에게 보내 독립 검토를 받습니다. 지적을 snapshot과 대조하고 provider가 필요한 기능을 제공하지 않으면 fail-closed로 멈춥니다. 검토는 근거를 제공하지만 최종 판정이나 코드 변경 권한을 갖지 않습니다.

저장소https://github.com/irootkernel/mulgae

Gaori(가오리)

Gaori는 긴 테스트 출력을 압축하면서도 판정 근거를 보존합니다. 성공과 실패는 실행한 명령의 exit code만으로 정하고, 원본 로그는 바꾸지 않은 채 남깁니다. Gaori의 요약은 테스트 실행기의 판정을 대신하지 않습니다.

저장소https://github.com/irootkernel/gaori

Sorage(소라게)

Sorage는 AI 코딩 세션 사이에서 문서를 전달하는 로컬 중개 도구입니다. 받는 쪽이 수락할 정확한 revision을 지정해야 교환이 끝나고, 종료 상태의 문서는 바뀌지 않습니다. Sorage는 편집기나 버전 관리 시스템, 작업 흐름 조정 도구가 아닙니다.

저장소https://github.com/irootkernel/sorage

Gul은 로컬 개발 runtime을 위한 LLM 없는 원격 조작 인터페이스로 계획 중입니다. 공개된 AI Harness 저장소는 모두 MIT 라이선스를 사용합니다.
