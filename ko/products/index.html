Products

Sudal, Doksuri, Ember Quest는 Root Kernel의 제어 원리를 실제 환경에서 검증하는 제품입니다. Sudal은 실시간 세션의 state transition을, Doksuri는 사람과 AI의 권한 경계를, Ember Quest는 결정적 실행을 검증합니다.

Sudal — 함께 답하고 비교하는 실시간 경험

Sudal은 이미 관계를 맺은 사람들이 같은 질문에 답하고 결과를 비교하며 서로의 취향과 생각을 발견하는 서비스입니다. 사진으로 남기기 어려운 닮은 점과 다른 점을 대화의 소재로 만듭니다.

한 번의 모임은 Raft라는 세션으로 열립니다. 각 참여자가 답을 고르고 Ready 상태에 도달한 뒤, 모두가 준비되었을 때만 비교 결과가 열립니다.

이 흐름은 gRPC 계약과 FSM을 결합한 AI-SPARK 세션 런타임이 운영합니다. 클라이언트는 상태를 직접 바꾸지 않고 이벤트만 보내며, 세션 런타임이 권한과 전이 조건을 검사한 뒤 실제 state transition을 수행합니다.

Sudal은 실제 사용자와 불안정한 네트워크에서도 이 제어 방식이 작동하는지 검증합니다. AI-SPARK 세션 런타임에서 확인한 원리는 설계부터 배포까지 포괄하는 AI-SPARK 개발 공정으로 이어졌습니다.

Doksuri — Markdown-first 프로젝트 관리

기존 프로젝트 관리 도구에서는 업무가 화면과 데이터베이스에 갇혀 기획 문서와 갈라집니다. AI에게 일을 맡길 때마다 내용을 다시 전달해야 하고, 결정의 배경과 현재 상태도 쉽게 어긋납니다.

Doksuri는 에픽과 작업, 버그를 각각의 Markdown 파일로 관리합니다. 데스크톱 앱, 편집기, 터미널이 같은 파일을 읽으므로 문서와 작업 상태가 한곳에 남습니다.

AI는 사람의 계정을 빌리지 않고 별도의 신원과 권한으로 참여합니다. 읽기와 댓글 같은 위험이 낮은 작업은 직접 수행할 수 있지만, 본문이나 상태를 바꾸는 변경은 제안으로 제출하고 사람이 승인합니다.

파일이 바뀌면 Doksuri는 구조와 허용된 상태를 먼저 검사합니다. 검증되지 않은 변경은 진단을 남기고 동기화 전에 멈추며, 중단된 작업을 성공으로 기록하지 않습니다.

Ember Quest — 불씨로 푸는 물리 퍼즐

Ember Quest는 불씨의 반사 경로를 읽어 성화대를 되살리는 세로 화면 퍼즐 RPG입니다. 방향과 힘을 정해 한 번 발사하면 되돌릴 수 없어 보이지 않는 공간과 제한된 시간을 함께 판단해야 합니다.

화면 표현과 게임 규칙을 분리하고 핵심 시뮬레이션을 fixed tick으로 실행합니다. 같은 스테이지와 명령은 기기나 실행 시점이 달라도 같은 결과를 만들며, replay는 다시 실행해 상태와 해시를 비교할 수 있는 기록입니다.

미로는 데이터로 작성되고 공통 runtime에서 실행됩니다. 게임에 반영하기 전에 구조 검사와 시뮬레이션을 거쳐 닿을 수 없는 성화대나 빠져나올 수 없는 반사 구조를 걸러냅니다.
