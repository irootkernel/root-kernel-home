Technology

AI-SPARK는 spec bundle에서 revision key를 만들고 검증, 사람의 승인, 구현, 배포가 모두 그 revision key를 가리키게 합니다. 승인 뒤 AI가 작성하는 코드는 이벤트, 전이 조건, 전이 동작에 집중하고, 실제 state transition과 동시성 제어, 전이 기록은 FSM runtime이 맡습니다. Podway는 작업마다 알맞은 절차를 세션 전에 정하고 검사해, 긴 작업이나 인수인계 뒤에도 다음 단계와 다시 해야 할 일을 잃지 않게 합니다.

Products

Sudal에서는 AI-SPARK 세션 런타임이 실시간 세션의 권한과 state transition을 통제합니다. Doksuri에서 AI는 사람과 분리된 신원과 권한으로 일하며 중요한 변경은 사람이 승인합니다. Ember Quest는 같은 입력에서 같은 결과를 내는 Deterministic Core로 게임 규칙과 replay를 검증합니다. 세 제품은 Root Kernel의 실행 원리가 실제 환경에서도 작동하는지 확인하는 검증장입니다.
