루트커널은 AI를 제어하는 기술을 만듭니다.

AI가 코드를 빠르게 만들어도, 의도대로 동작하는지 검토하고 문제가 생겼을 때 복구하는 일은 여전히 어렵고 시간이 많이 듭니다. 루트커널은 AI의 작업 범위와 실행 절차를 정하고, 사람이 정한 규칙과 승인에 따라 AI가 일하도록 제어하는 기술을 만듭니다. 각 단계의 검증 조건을 충족해야 다음 단계로 넘어가고, 사람의 판단이 필요한 지점에서는 승인을 받아 실행을 이어갑니다.

Technology

AI-SPARK는 spec bundle에서 revision key를 만들어 명세 버전을 식별합니다. 검증과 사람의 승인, 구현과 배포는 모두 이 버전을 기준으로 진행합니다. 승인 후 AI는 이벤트 발생과 전이 조건, 전이 동작에 필요한 코드를 작성합니다. FSM runtime은 실제 상태 전이를 실행하고 동시성을 제어하며, 전이 기록을 남깁니다. Podway에서는 작업에 맞는 절차를 미리 정하고 실행 전에 검증합니다. 작업이 길어지거나 다른 사람이나 에이전트에게 넘겨도, 다음에 진행할 단계와 다시 수행할 작업을 확인할 수 있습니다.

AI Harness

AI Harness는 AI 에이전트와 함께 소프트웨어를 개발할 때 사용하는 도구군입니다. 작업 진행 상황을 추적하고, 에이전트가 마쳤다고 보고한 작업을 테스트 결과와 실행 기록으로 확인합니다. 중요한 변경은 사람이 승인합니다. 루트커널이 직접 만들어 자사 제품과 도구 개발에 활용하고 있으며, 오픈소스로 공개했습니다.

  • Aquarium
  • Podway
  • Dolgorae
  • Sanho
  • Mulgae
  • Gaori
  • Sorage

AI Agent

루트커널은 Hermes Agent를 업무에 적극적으로 활용하며, 필요한 기능을 직접 수정하고 확장합니다. 에이전트 간 토론을 위해 Agent Turn Network를 만들고, Hermes Agent에서 LLM Wiki를 활용하기 위한 Agent Dispatch를 개발했습니다. Hermes Agent 수정본과 두 도구는 모두 오픈소스로 공개했습니다.

  • Hermes Agent
  • Agent Turn Network
  • Agent Dispatch

Products

루트커널은 AI Harness와 AI Agent를 활용해 제품을 기획하고 개발합니다. 직접 만든 도구와 에이전트를 제품 개발에 적용하면서, 실제 작업에 필요한 기능과 해결해야 할 문제를 구체화합니다. 그 경험을 다시 기술에 반영해 제품과 개발 도구를 함께 개선합니다.

Principles

루트커널은 AI의 자율성을 넓히면서도 사람이 작업의 방향과 중요한 결정을 통제할 수 있어야 한다고 봅니다. 작업 범위와 검증 기준을 먼저 정하고, 결과를 확인하고 판단을 되짚을 수 있도록 작업 과정을 기록합니다. 문제가 생겼을 때도 작업 내용을 보존하고 이어갈 수 있도록 제품과 도구를 설계합니다.
