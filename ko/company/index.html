ROOT KERNEL / COMPANY

Company

루트커널은 AI의 작업을 제어하는 기술과 이를 활용한 제품을 만드는 회사입니다. 2026년 6월에 설립했으며, 대표 한 사람이 여러 AI 에이전트와 함께 연구하고 개발합니다.

이름에 담은 뜻

Kernel이라는 이름은 대표의 연구와 개발 경험에서 나왔습니다. 석사 과정에서는 반복문 커널의 성능을 높이는 컴파일러 기술을 연구했고, LG전자에서는 Linux Kernel 개발을 맡았습니다. SAP에서는 Kernel 팀에서 세션과 트랜잭션을 관리하고 여러 SQL 엔진을 연결하는 RDBMS 코어 기술을 개발했습니다.

Root는 시스템에서 가장 높은 권한을 뜻하면서, 근원과 뿌리라는 의미도 지닙니다. Root Kernel에는 그동안 다뤄 온 복잡하고 거대한 커널 시스템의 근간이 되는 기업으로 성장하겠다는 의지를 담았습니다.

동물 이름으로 표현한 제품과 기술

생명이 바다에서 시작됐듯이, 제품을 만드는 기반 기술을 수중 동물에 빗대어 개발 도구에 물개, 가오리, 산호 같은 이름을 붙였습니다. 사람들의 일상에 쓰이는 B2C 제품은 육상 동물로, 기업의 성장과 협업을 돕는 B2B 제품은 하늘의 동물로 표현합니다. Sudal은 사람들의 관계를 다루는 B2C 제품이고, Doksuri는 사람과 AI의 협업을 돕는 B2B 제품입니다.

창업자

대표 정영훈은 모바일 운영체제와 데이터베이스 코어, 클라우드 인프라를 개발해 온 13년 경력의 엔지니어입니다. LG전자에서는 Linux Kernel 스케줄러와 전력 관리 시스템을, SAP Labs Korea에서는 SAP HANA의 데이터베이스 코어와 클라우드 인프라를 개발했습니다.

데이터베이스에 장애가 발생해도 세션을 이어가는 복구 기술과, 실제 운영 워크로드를 재현해 변경 사항을 검증하는 기술 등을 개발했습니다.

국내 금융권의 2026 기업뱅킹 고도화 프로젝트에 참여해 금융 애플리케이션을 개발하고 있습니다.
