그래서 회사 이름도 루트커널인 거야?

ROOT KERNEL

네. Kernel은 연구와 개발을 통해 계속 다뤄 온 기술입니다. Root에는 시스템의 가장 높은 권한과 근원이라는 뜻이 있습니다. 그동안 다뤄 온 복잡하고 거대한 커널 시스템의 근간이 되는 기업으로 성장하겠다는 뜻을 담았습니다. 도구와 제품의 이름에도 저마다의 의미가 있습니다.

COMPANY / 회사 이름

이름에 담은 뜻

Root_

Root는 시스템에서 가장 높은 권한을 뜻하면서, 근원과 뿌리라는 의미도 지닙니다.

Kernel_

Kernel이라는 이름은 대표의 연구와 개발 경험에서 나왔습니다. 석사 과정에서는 반복문 커널의 성능을 높이는 컴파일러 기술을 연구했고, LG전자에서는 Linux Kernel 개발을 맡았습니다. SAP에서는 Kernel 팀에서 세션과 트랜잭션을 관리하고 여러 SQL 엔진을 연결하는 RDBMS 코어 기술을 개발했습니다.

Root Kernel에는 그동안 다뤄 온 복잡하고 거대한 커널 시스템의 근간이 되는 기업으로 성장하겠다는 의지를 담았습니다.
