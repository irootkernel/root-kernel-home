AI Agent

루트커널은 파일 변경을 에이전트 작업으로 넘기는 Agent Dispatch와, 여러 에이전트가 한 주제를 토론하도록 연결하는 Agent Turn Network를 만들었습니다. 실행에는 Hermes Agent를 활용합니다. 이 도구들은 오픈소스로 공개했습니다.

Hermes Agent는 Nous Research의 오픈소스 AI 에이전트입니다. 루트커널의 자체 포크는 Deprecated입니다. 업무에 필요했던 중요 변경은 지금 업스트림으로 PR을 보내고 있습니다.

Agent Turn Network(ATN)는 여러 Hermes 에이전트가 하나의 주제를 함께 토론하도록 연결하는 도구입니다. 진행자와 참여 에이전트를 정해 의견을 주고받고, 논의 과정과 결론을 기록해 다시 확인할 수 있습니다.

ATN Control은 토론의 진행 상태와 기록을 관리하고, ATN Plugin은 Hermes 에이전트가 토론에 참여할 수 있도록 연결합니다.

Agent Dispatch는 지정한 디렉터리의 파일 변경을 감지해, 설정한 규칙에 따라 Hermes Agent에 작업을 전달하는 도구입니다. LLM Wiki 갱신처럼 변경된 내용에 맞춰 에이전트가 필요한 처리를 수행하도록 연결합니다. 반복되는 변경 알림은 모아 처리하고, 에이전트의 수정이 불필요한 재실행으로 이어지지 않도록 관리합니다.

Agent Dispatch는 파일 변경을 작업으로 넘기고, Agent Dispatch Plugin은 Hermes 대화에서 경로와 작업 기록, receipt를 조회할 수 있게 연결합니다.
