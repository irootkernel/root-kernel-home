AI Agent

AI Agent는 에이전트 실행, 위임과 심의의 기록, 검토된 결과의 전달을 서로 다른 구성 요소에 나눠 맡깁니다.

Hermes Agent가 에이전트를 실행하고, Agent Turn Network가 위임과 심의의 상태와 event log를 관리하며, Agent Dispatch가 받아들인 파일 변경을 다음 작업으로 전달합니다. 메시지는 증거를 가리키는 표식일 뿐 수명주기 상태 자체가 아닙니다.

Hermes Agent

Hermes Agent는 Nous Research 업스트림에서 포크한 자기 개선 에이전트의 검증 릴리스 계열입니다. 여러 모델과 실행 기반을 지원하되 독립 검토와 테스트를 통과한 빌드만 릴리스로 제공합니다.

저장소https://github.com/irootkernel/hermes-agent/releases/tag/rk%2Ftag%2Fv0.20.5

Agent Turn Network Control

Agent Turn Network Control은 위임과 심의의 상태를 결정하는 기준입니다. 상태는 하나의 event log에서 계산되고 SQLite는 다시 만들 수 있는 조회용 표현이므로, 어떤 결론에 이른 경로를 추적할 수 있습니다. 손상된 로그나 알 수 없는 프로토콜 기능은 구조화된 오류와 함께 fail-closed로 멈춥니다.

저장소https://github.com/irootkernel/agent-turn-network-control

Agent Turn Network Plugin

Agent Turn Network Plugin은 Hermes에서 ATN을 호출하는 전송 계층과 도구 인터페이스입니다. 상태를 소유하지 않고 호출자가 준 식별자를 그대로 전달하며, 명시되지 않은 데몬을 자동으로 찾거나 다른 대상으로 바꾸지 않습니다.

저장소https://github.com/irootkernel/agent-turn-network-plugin

Agent Dispatch

Agent Dispatch는 파일 변경 이벤트를 결정적 편집 계획과 확인 가능한 receipt로 바꿉니다. 검증된 계획만 지속되는 작업으로 내보내며 형식 검사, 테스트, 스키마 검증 결과를 함께 남깁니다.

저장소https://github.com/irootkernel/agent-dispatch
