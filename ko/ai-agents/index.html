AI Agent

루트커널은 Hermes Agent를 업무에 활용하면서 필요한 기능을 직접 수정하고 확장합니다. 여러 에이전트가 의견을 주고받으며 토론할 수 있도록 Agent Turn Network를 만들고, Hermes Agent에서 LLM Wiki를 활용하기 위한 Agent Dispatch를 개발했습니다. Hermes Agent 수정본과 이 도구들은 모두 오픈소스로 공개했습니다.

Hermes Agent

Hermes Agent는 Nous Research의 오픈소스 AI 에이전트입니다. 루트커널은 이를 포크해 업무에 필요한 기능을 보완하고 직접 사용합니다. 한글 대화 기록의 복구와 검색, 에이전트가 사용할 계정의 지정, Discord에서의 대화 참여 제어 등 실제 운영에 필요한 부분을 개선했으며, 수정본을 오픈소스로 공개했습니다.

Agent Turn Network(ATN)

Agent Turn Network(ATN)는 여러 Hermes 에이전트가 하나의 주제를 함께 토론하도록 연결하는 도구입니다. 진행자와 참여 에이전트를 정해 의견을 주고받고, 논의 과정과 결론을 기록해 다시 확인할 수 있습니다.

ATN Control은 토론의 진행 상태와 기록을 관리하고, ATN Plugin은 Hermes 에이전트가 토론에 참여할 수 있도록 연결합니다.

Agent Dispatch

Agent Dispatch는 지정한 디렉터리의 파일 변경을 감지해, 설정한 규칙에 따라 Hermes Agent에 작업을 전달하는 도구입니다. LLM Wiki 갱신처럼 변경된 내용에 맞춰 에이전트가 필요한 처리를 수행하도록 연결합니다. 반복되는 변경 알림은 모아 처리하고, 에이전트의 수정이 불필요한 재실행으로 이어지지 않도록 관리합니다. Hermes용 플러그인도 개발 중입니다.
