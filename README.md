# Root Kernel Home

Static website package for GitHub Pages (`https://home.rootkernel.xyz`).

The published HTML, CSS, and JS are generated by the sibling private repo
`root-kernel-home-generator`. Do not edit generated locale pages, redirect stubs,
`404.html`, `index.html`, `sitemap.xml`, `assets/css/site.css`, or `assets/js/rk.js`
by hand.

```bash
cd ../root-kernel-home-generator
make build
make test
make publish    # commits this tree and pushes GitHub Pages
```
