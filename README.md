# Root Kernel Home

Static GitHub Pages site at https://home.rootkernel.xyz.

The current bilingual TUI homepage is generated by the sibling private
`root-kernel-home-generator` repository from `r5/v4/monitor`.
Do not edit generated pages or runtime assets by hand.

```sh
cd ../root-kernel-home-generator
node r5/v4/monitor/build.mjs
node --test r5/v4/monitor/*.test.mjs
node r5/v4/monitor/deliver.mjs
```

The delivery command copies generated files without removing legacy routes,
`CNAME`, `.nojekyll`, icons, or repository configuration. Review and commit both
repositories, push the generator first, then push this repository's `main` branch.
GitHub Pages publishes that branch from the repository root.

Do not use the legacy generator `make build` or `make publish` targets for v4.
`build-info.json` identifies the source hashes and runtime asset version.
