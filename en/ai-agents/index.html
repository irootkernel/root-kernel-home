ROOT KERNEL / AI AGENT

AI Agent

Root Kernel built Agent Dispatch to turn file changes into agent work, and Agent Turn Network so several agents can discuss a topic. The tools use Hermes Agent and are available as open source.

Hermes Agent is an open-source AI agent from Nous Research. Root Kernel's own fork is deprecated. The important changes from that work are now going upstream as pull requests.

Agent Turn Network (ATN) connects multiple Hermes agents to discuss a shared topic. A moderator and participating agents exchange views, with the discussion and conclusions recorded for later reference.

ATN Control manages discussion progress and records, while ATN Plugin connects Hermes agents to the discussion.

Agent Dispatch detects file changes in a specified directory and sends work to Hermes Agent according to configured rules. It connects changes to the agent’s next action, such as updating an LLM Wiki. Repeated change notifications are grouped, and edits made by the agent are managed to avoid unnecessary reruns.

Agent Dispatch turns file changes into work, while Agent Dispatch Plugin connects Hermes conversations so routes, dispatch history, and receipts can be inspected.
