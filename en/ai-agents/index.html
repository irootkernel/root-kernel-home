AI Agent

The AI Agent layer separates agent execution, records of delegation and deliberation, and the delivery of reviewed results across distinct components.

Hermes Agent runs agents, Agent Turn Network manages state and the event log for delegation and deliberation, and Agent Dispatch carries accepted file changes into the next task. Messages point to evidence; they are not lifecycle state themselves.

Hermes Agent

Hermes Agent is a verified release line forked from the Nous Research upstream. It supports multiple models and backends, while publishing only builds that pass independent review and testing.

Repositoryhttps://github.com/irootkernel/hermes-agent/releases/tag/rk%2Ftag%2Fv0.20.5

Agent Turn Network Control

Agent Turn Network Control is the state authority for delegation and deliberation. State is derived from one event log, with SQLite serving as a rebuildable view, so the path to every conclusion can be traced. A damaged log or unknown protocol feature stops fail-closed with a structured error.

Repositoryhttps://github.com/irootkernel/agent-turn-network-control

Agent Turn Network Plugin

Agent Turn Network Plugin is the transport and tool interface through which Hermes calls ATN. It owns no state, preserves identifiers supplied by the caller, and neither discovers nor substitutes an unspecified daemon automatically.

Repositoryhttps://github.com/irootkernel/agent-turn-network-plugin

Agent Dispatch

Agent Dispatch turns file-change events into deterministic edit plans and verifiable receipts. Only validated plans are emitted as durable tasks, with formatting checks, tests, and schema-validation results recorded alongside them.

Repositoryhttps://github.com/irootkernel/agent-dispatch
