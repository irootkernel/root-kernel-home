YOU

Doksuri is an unusual name — how do you actually work with AI using it?

ROOT KERNEL

We built Doksuri and use it with Hermes Agent. The name comes from the Korean for eagle. It watches Markdown with a hawk’s eye, then nimbly snatches the files you need and puts them in front of you. People and AI divide work on the same project, then share progress and results.

ROOT KERNEL
