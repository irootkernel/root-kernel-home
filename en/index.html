Root Kernel builds technology that controls AI.

Even when AI writes code quickly, checking that it works as intended and recovering when something goes wrong still takes time and effort. Root Kernel builds technology that defines the scope and process of AI work, keeping it subject to human-defined rules and approvals. Work advances only when each stage meets its validation criteria; where human judgment is needed, execution continues after approval.

Technology

AI-SPARK derives a revision key from a spec bundle to identify its version. Validation, human approval, implementation, and deployment all use that version. After approval, AI writes code for events, transition conditions, and transition actions. The FSM runtime executes state transitions, controls concurrency, and records transitions. With Podway, a procedure is defined for each task and validated before execution. Even during long tasks or handoffs to another person or agent, the next stage and any work that needs to be repeated remain visible.

AI Harness

AI Harness is a set of tools for developing software with AI agents. It tracks progress and checks agents’ reports of completed work against test results and execution records. People approve consequential changes. Root Kernel develops these tools, uses them to build its own products and tools, and has released them as open source.

Principles

Root Kernel believes AI should have room to act autonomously while people retain control over the direction of work and consequential decisions. We define scope and validation criteria first, then record the process so results can be checked and decisions revisited. We design products and tools to preserve work and allow it to continue when problems arise.
