Technology

AI-SPARK derives a revision key from the spec bundle and binds validation, human approval, implementation, and deployment to it. After approval, AI-written code focuses on events, guards, and actions, while the FSM runtime owns state transitions, concurrency control, and transition logging. Podway selects or configures and checks a Procedure v2 for each task before the session, preserving the next step and required rework across long runs and handoffs.

Products

In Sudal, the AI-SPARK session runtime controls permissions and state transitions for live sessions. In Doksuri, AI works under an identity and permissions separate from a person's, and a person approves consequential changes. Ember Quest tests game rules and replays on a Deterministic Core that produces the same result from the same input. Together, the products test Root Kernel's execution principles in real operating environments.
