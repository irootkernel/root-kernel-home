YOU

What is Root Kernel?

ROOT KERNEL

Root Kernel is a software company that builds technology to keep AI working only within defined boundaries and procedures. We structure the work assigned to AI, how it is verified, and the steps for returning and recovering when something goes wrong.

ROOT KERNEL / AI AGENT SYSTEMS

Root Kernel builds
technology that controls AI.

Even when AI writes code quickly, reviewing whether it works as intended and recovering from problems still takes time and effort.

Root Kernel defines what AI should do and how its work will be checked,
along with the stage to return to when something goes wrong.
AI follows this procedure and proceeds with human approval.

build AI agent systems
YOU

How do you control the way AI works?

ROOT KERNEL

Root Kernel develops a range of AI control technologies and tools. AI-SPARK guides AI to write code from specifications that have been validated and approved by a person. Podway extends these principles to tasks such as analysis, documentation, and review. It manages work stages and transition conditions, returning to the necessary stage to repeat work and verification when a problem is found. We have also released other tools for controlling AI work as open source.

TECHNOLOGY

Two FSM-based technologies
for controlling AI

An FSM defines the possible states and the conditions for moving between them.

01

AI-SPARK

AI writes code from specifications that have passed validation and human approval. The FSM runtime controls the actual state transitions.

02

Podway

Define the procedure and conditions for each stage before the task begins. If rework is needed, the task returns along a predefined path.
